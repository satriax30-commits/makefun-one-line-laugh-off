A make.fun entry for the **One-Line Laugh-Off** bounty: one original one-liner,
written by a tiny deterministic Node program to `/output/entry.txt`.

The joke: a horoscope promises the narrator will meet someone special today —
so they stay home, because they don't want to disappoint them. The twist
reframes the whole setup in the final words.

## Run it

```sh
node main.ts
```

This writes the single joke line to `/output/entry.txt` (UTF-8, one line,
1–200 characters). No network, no randomness, no clock — the same bytes every
run.
